# Achird Local

[themoonlight.io](https://www.themoonlight.io/ko)의 논문 읽기 경험을 로컬에서 재현한 앱.
AI는 **Claude Code CLI(`claude -p`) 구독을 재사용** — API 키가 필요 없다.

## 스크린샷

![서가 화면](docs/screenshots/01-home.png)
서가 — 논문마다 읽는 중/완독 상태를 한눈에 보여준다.

![리더 화면](docs/screenshots/02-reader.png)
리더 — 왼쪽은 렌더링된 PDF, 오른쪽은 자동 생성된 요약 패널.

![다른 논문의 리더 화면](docs/screenshots/03-reader-2.png)
같은 리더로 다른 논문을 연 화면. 요약 패널에 구조 분석이 채워져 있다.

## 실행

`run.bat` 더블클릭 → Edge/Chrome 앱모드 창이 자동으로 열린다 (`http://127.0.0.1:8766`).

- 첫 실행이면 가상환경을 만들고 fastapi/uvicorn을 설치한다 (1~2분).
- 브라우저 없이 서버만: `run.bat --no-browser`
- 백그라운드(자동화·Claude): `start-bg.bat` — 서버를 **최소화 창**으로 분리 실행(숨김 아님).
  자동 실행 시 `Start-Process -WindowStyle Hidden`은 쓰지 말 것 — Windows Defender가
  `Trojan:Win32/PowhidSubExec`(PowerShell+숨김창+하위프로세스)로 오탐·격리한다.
- 전제: `claude` CLI가 로그인돼 있을 것 (`claude` 실행 후 `/login`).

## 두 개의 탭

상단 세그먼트로 **읽기 / 쓰기**를 오간다.

- **읽기** — 한 편을 이해하는 도구. 서가·검색·서재 질문·논문 비교·인용 그래프·대기열.
- **쓰기** — 여러 편을 가로질러 뽑아내는 도구. 왼쪽에 서재 전체의 근거, 오른쪽에 절 단위 초안.
  근거를 절에 담고, 커서 자리에 인용을 넣고, 겹침을 검사하고, 출처가 붙은 Markdown으로 내보낸다.

쓰기 탭은 **워드프로세서가 아니다.** 서식·문단 편집·문장 자동 생성은 일부러 넣지 않았다 —
Achird는 근거와 출처를 소유하고, 산문은 Word·한글·Obsidian이 소유한다.

## 기능 (themoonlight 대비)

| 기능 | 사용법 |
|---|---|
| PDF 뷰어 | 지연 렌더·줌·쪽 이동. 첫 열람 시 본문 자동 추출 |
| 자동 준비 체인 | 업로드·Zotero 가져오기 직후 백그라운드로 서지→요약→핵심 4색→용어집→추천 질문→출처 검증까지 자동(번역 제외 — 읽을 때 결정). 서가 카드에 "준비 n/7" 배지, 홈 백그라운드 작업의 "서재 준비"로 기존 논문 소급, 내보내기 탭에서 자동 실행 끔. 본문은 pypdf로 서버가 먼저 뽑고(임시본) 첫 열람 때 pdf.js 정본으로 교체 |
| 복습 카드 | Obsidian 내보내기 때 강조·노트 있는 논문만 Haiku가 Q/A 카드 5~8장 생성 → vault `flashcards/@citekey.md` (obsidian-spaced-repetition 플러그인 형식). 강조가 바뀔 때만 재생성 — 안 바뀌면 파일을 안 건드려 복습 스케줄이 보존된다 |
| 병렬 읽기 | 원문·번역 2단 뷰 + 문장 연결(원문↔번역 하이라이트 동기) |
| 페이지 번역 | 툴바 번역 버튼 → 논문 전체를 페이지 단위로 번역. 용어집 반영, 페이지별 캐시 |
| 한국어 요약 | 우측 패널 "요약" 탭 → 생성 (Sonnet). 이후 캐시로 즉시 표시 |
| 구조 분석 | "분석" 탭 → 기본정보·배경·이론·방법·데이터·결과·한계·적용 8칸 고정. 논문에 없는 칸은 비워 둔다. 8칸이 근거 보드에도 들어가 절에 담긴다 |
| 마인드맵 | 툴바 지도 버튼 또는 `M`. 이 논문이 실제로 세우는 논지 축과 그 근거를 방사형 한 장으로. **모든 마디가 본문 한 문장을 가리킨다 — 누르면 그 쪽으로 뛰고 문장이 잠깐 반짝인다.** 핵심 4색으로 색이 붙고, Markdown 개요·SVG로 내보낸다 |
| 핵심 4색 하이라이트 | 독창성(분홍)·방법(연두)·결과(연보라)·한계(하늘). 수동 강조 + "AI 핵심 문장 찾기" |
| 노트 및 형광펜 | 드래그 → 노트/형광펜 표시. "노트"·"강조" 탭에서 관리 |
| 용어집 | 본문 밑줄 + 호버 툴팁. 인라인 정의 표시 |
| 참고문헌 | 본문의 `[n]` 클릭 → 서지 팝업. "인용" 탭에 전체 목록. 원문 인용 핫스팟 |
| 출처 검증 | "인용" 탭 → "출처 검증". 참고문헌 한 줄씩 DOI를 확정하고(본문 DOI → Crossref → arXiv) 연도·저널·링크를 붙인다. 확인 못 한 건 ⚠ 미확인으로 남긴다 — 지어내지 않는다 |
| 그림·표 AI 해설 | 드래그 캡처(C)·선택 메뉴로 AI 설명. 그림 탭 갤러리 |
| 스캔 PDF | 감지 시 배너 표시 + 내장 AI OCR (Vision) 제공 |
| 메타데이터 | 저자·연도·학회·DOI 자동 추출 |
| 논문 채팅 | "채팅" 탭. 전문이 컨텍스트. 드래그 → "채팅 인용"으로 구절 첨부 + 추천 질문 |
| 서재 검색 | 원문·번역·내 노트·강조 + 내보낸 Obsidian 노트의 "내 메모"까지 한 번에 검색 + 서재 질문(근거 구절 인용). 논문 2~3편 비교 |
| 근거표 | 선택 모드 → 2~8편 → "근거표". 대상·방법·데이터·결과·한계 표. Markdown/CSV 내보내기·복사. 만든 표는 "저장된 근거표"에서 다시 꺼낸다 |
| 근거 보드 | 쓰기 탭 왼쪽. 서재 전체의 강조·노트·핵심 4색을 한 목록으로. 분류·논문으로 좁히고 "담기"로 절에 붙인다 |
| 절 단위 초안 | 쓰기 탭 오른쪽. 절을 만들고 본문을 쓴다. 자동 저장(`library/_draft.json`), 담은 근거의 "인용"을 누르면 커서 자리에 `(저자, 연도, p.N)` |
| 번호 인용 | 선택 모드 → "번호 인용" (또는 쓰기 탭 툴바 = 서재 전체). 고른 순서대로 [1]…[N] + ACS/APA/BibTeX 목록 |
| 초안 점검 | 절마다 "겹침 검사". 서재 원문·번역과 8어절 이상 겹치는 곳을 표시. AI를 쓰지 않아 즉시 끝난다 |
| 초안 채점 | 절마다 "초안 채점". 담아놓고 안 쓴 근거·인용 밀도·대표 역어 위반·인용 무결성은 AI 없이 즉시, 구조 지적과 3인 가상 심사(엄격·방법론·분야 밖 독자)는 모델이. 고쳐 쓴 문장은 내놓지 않는다 |
| 인용 무결성 | 초안 채점에 함께 나온다. 본문의 `(저자, 연도, p.N)`을 서재와 대조 — 그 논문 쪽수를 넘겼는지, 그 쪽에서 담아둔 근거가 이 절에 있는지. 서재에 없는 출처는 오류가 아니라 정보로만 표시한다 |
| 근거 커버리지 | 쓰기 탭 절 탭 아래 막대. 절마다 담은 근거 수를 한 줄로 보여준다 — 위험한 건 근거가 적은 절이 아니라 **0건인 절**이고, 본문이 채워져 있으면 눈으로는 안 보인다 |
| 통합 용어집 | 논문별 용어집을 합쳐 역어가 갈린 용어를 보여준다. 대표 역어를 고정하면 이후 번역이 그것으로 통일된다 |
| 심화 검색 | "인용" 탭 → "심화 검색". OpenAlex로 이 논문을 인용한 논문·관련 논문을 찾고, 서재에 이미 있으면 표시한다 |
| 논문 찾기 | 홈 → "논문 찾기". 심화 검색이 이 논문과 이어진 것만 보여준다면, 여기는 주제어로 처음부터 찾는다(OpenAlex, 연도 하한·페이지 넘김) |
| 연구 트렌드 | 홈 → "연구 트렌드". **관심 분야를 고르라고 묻지 않는다 — 서재가 곧 관심사다.** 서재 논문의 OpenAlex topic을 집계해 상위 3개를 뽑고, 그 주제의 최근 90일 논문을 피인용 순으로 보여준다 |
| 다시 볼 논문 | 홈 → "다시 볼 논문". 강조·노트를 남겼는데 오래 안 연 편만 부른다 — 다시 볼 이유가 있어야 큐에 오른다 |
| 백그라운드 번역 | 홈 → "백그라운드 작업", 또는 병렬 뷰의 "백그라운드로". 서버가 돌리므로 리더를 닫거나 다른 논문을 읽어도 계속된다. 번역 안 된 쪽만 골라 돌아 다시 눌러도 안전하다 |
| 근접 중복 | 업로드는 sha256 완전일치를 막는다. 그물을 빠져나간 프리프린트본·재다운로드본은 DOI·제목으로 잡아 리더에 배너로 알린다 — **막지는 않는다** |
| 읽을 논문 대기열 | 심화 검색·논문 찾기 결과에서 "담기". 나중에 그 PDF를 올리면 자동으로 "서재에 있음"으로 바뀐다 |
| 인용 그래프 | 홈 → "인용 그래프". 서재 안의 인용 관계를 원형 배치로. 출처 검증을 돌렸으면 DOI 완전일치로 이어진다. "노트 개념 포함"을 켜면 노트 메모의 `[[개념]]`이 노드가 되어, 서로 인용하지 않는 논문도 같은 개념으로 묶인다 |
| 내보내기 | Obsidian 내보내기(메모 보존, "변경분만" 증분 지원). 노트에 Achird·Zotero 왕복 링크 + `@citekey` alias(볼트 어디서든 `[[@citekey]]`로 연결) + 초록 섹션이 붙고, 노트 폴더에 서재 전체 `achird.bib`이 함께 갱신된다. 초안 `.docx`(본문 + 절별 근거 + 번호 참고문헌) |
| Zotero 연동 | 가져오기(PDF + DOI·저자·연도·저널·초록·citekey를 통째로 — AI 재추출 불필요) · Zotero PDF 리더의 형광펜을 강조로 가져오기("강조" 탭, 중복 자동 제거, 새 주석 수 배지) · 심화 검색·대기열에서 발견한 논문을 실행 중인 Zotero에 저장("Zotero" 버튼, 커넥터 포트 23119) · 홈 Zotero 버튼에 안 가져온 항목 수 배지 · 대기열 논문의 PDF가 Zotero에 도착하면 "가져오기" 버튼이 뜬다(DOI 매칭) |
| citekey 인용 | 내보내기 탭에서 켜면 쓰기 탭 "인용"이 `(저자, 연도, p.N)` 대신 pandoc식 `[@citekey, p.N]`을 넣는다. BibTeX 키도 Zotero(Better BibTeX) citekey를 정본으로 쓴다. 초안 채점·인용 무결성도 이 표기를 인식한다 |

## 저장 위치

- 논문·요약·구조 분석·마인드맵·노트·채팅·읽던 위치: `library/<id>/` (이 폴더째 백업하면 끝)
  읽던 위치는 `meta.json`에 들어간다 — 예전엔 브라우저에만 있어서 PC를 바꾸면 진행률이 0으로 보였다.
- 서재 전체에 걸친 것: `library/_draft.json`(초안) · `library/_glossary.json`(대표 역어) ·
  `library/_queue.json`(읽을 논문) · `library/_table_*.json`(근거표)
- OneDrive 아래에 두는 경우 `library/`를 "항상 이 디바이스에 유지"로 설정하길 권장
  (자리표시자 상태면 첫 열람이 느려진다).

## 구조

```
app.py     FastAPI 서버 + claude -p 러너 (기본 Sonnet, 단순 작업만 Haiku)
static/    SPA 프론트엔드 (pdf.js 4.8.69 벤더링, 오프라인 동작)
library/   논문별 데이터 (pdf, text.json, summary.md, analysis.json, mindmap.json, chat.json, notes.json, refs.json, …)
tests/     순수 함수 회귀 테스트 (stdlib unittest, 추가 의존성 없음)
run.bat       실행기 (venv 자동 구성, 앱모드 창)
start-bg.bat  백그라운드 실행기 (최소화 창, 자동화용 — 숨김 실행 금지)
run_tests.bat 테스트 러너 (= `python run_tests.py` = `python app.py --self-check`)
```

코드를 고쳤으면 `run_tests.bat`을 한 번 돌린다. 세 진입점 모두 같은 `tests/`를 실행하고,
실패하면 종료코드 1로 떨어진다. 케이스를 추가할 곳은 `tests/test_pure.py` 한 군데다.

## 문제 해결

- **창은 떠 있는데 "서버와 연결할 수 없습니다" / PDF 열기 실패**: 서버가 꺼진 상태다 (재부팅 후 창만 남은 경우 등).
  `run.bat`을 다시 실행하면 된다 — 서버가 이미 살아 있으면 창만 다시 연다.
- **AI 호출 실패**: 터미널에서 `claude -p "hi"`가 되는지 확인. 구독 로그인 필요.
- **출처 검증에서 미확인이 많음**: 서지 문장에 DOI도 arXiv 번호도 없고 Crossref에 등재되지 않은 학회(ICLR·NIPS·JMLR 등) 인용은 확인할 방법이 없다. 실측(Attention Is All You Need, 40건): 28건 확인 · 12건 미확인 — 미확인 12건은 전부 DOI 없는 학회 논문이었다. 학술지 인용이 대부분인 분야에서는 확인율이 훨씬 높다.
- **연구 트렌드의 주제가 엉뚱함**: 주제는 서재 논문의 OpenAlex topic을 집계한 것이라, 서재가 작으면 논문 한 편이 곧 한 주제가 된다(각 주제 옆 "(N편)"이 그 숫자다). 편수가 쌓여야 쓸 만해진다. 서지정보(DOI·제목)가 없는 논문은 주제를 못 뽑으므로 "인용" 탭에서 먼저 추출할 것.
- **.docx 버튼이 실패함**: `python-docx`는 선택 의존성이다 — `run.bat`을 한 번 다시 실행하면 설치된다. 없어도 앱의 나머지는 그대로 돈다.
- **마인드맵 마디가 "본문 매칭 실패"**: 앵커 문장을 본문에서 못 찾은 경우다(스캔 PDF·수식 뒤섞임). 그 마디는 흐리게 표시되고 클릭 대상에서 빠진다. 뿌리와 구조 마디(가지 이름)는 애초에 가리킬 문장이 없으므로 실패가 아니다.
- **심화 검색·논문 찾기·출처 검증·연구 트렌드 실패**: 이들만 인터넷이 필요하다(OpenAlex·Crossref, 키·가입 불필요).
  심화 검색은 DOI가 없으면 제목으로 찾으므로 "인용" 탭에서 서지정보를 먼저 추출하면 정확도가 올라간다.
  심화 검색 결과는 논문별로 캐시되고 "다시 받기"로만 갱신한다. 출처 검증 결과는 `refs.json`에 남아
  다시 눌러야만 갱신된다. 논문 찾기는 질의가 매번 달라 캐시하지 않는다.
- **번역이 느림**: 번역·요약·채팅은 품질 때문에 Sonnet을 쓴다. 단순 작업(문장 정렬, 서지정보 추출,
  서재 질문의 키워드 뽑기)은 이미 Haiku다. 더 빠르게 하려면 `app.py`의 `ask_claude(... model="sonnet")`
  기본값을 `haiku`로 바꾸면 되지만 번역 품질이 눈에 띄게 떨어진다.
- **초안 점검에 겹침이 하나도 안 뜸**: 겹침은 **원문·번역에 실제로 있는 문자열**과 대조한다. 한국어로 쓴 초안은
  그 논문을 먼저 번역해 둬야 걸린다(번역 안 된 논문은 영어 원문하고만 비교된다). 반대로 겹침이 떴다고 곧 표절은
  아니다 — 인용부호를 빠뜨렸거나 요약이 아직 원문에 붙어 있는 곳을 스스로 보라는 표시다.
- **통합 용어집에서 대표 역어를 고쳤는데 번역이 그대로**: 이미 번역된 페이지는 캐시에서 나온다. 그 쪽을
  다시 번역해야 새 역어가 반영된다.
- **PC를 바꿨더니 Obsidian 볼트·Zotero 경로가 깨짐**: `config.json`은 앱 폴더에 있어 OneDrive로 두 PC가
  함께 쓰는데, 절대경로에 박힌 사용자명은 PC마다 다르다. 앱이 쓰는 순간 `C:\Users\<다른이름>\나머지`를
  이 PC 홈(`C:\Users\<내이름>\나머지`)으로 되짚어 보고, 그 폴더가 실제로 있으면 그쪽을 쓴다. 저장된 값은
  건드리지 않으므로 반대편 PC도 계속 동작한다. 되짚은 자리에도 폴더가 없으면 원래 경로를 그대로 알려준다.
- **글자가 안 긁힘**: 스캔 PDF(이미지)는 텍스트 레이어가 없다. 앱이 자동으로 감지하고 배너에서 AI OCR(Vision)을 실행할 수 있다. 텍스트 기반 PDF 사용 권장.
